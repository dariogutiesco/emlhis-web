QUÉ SUBIR Y DÓNDE
=================

Descomprime el zip. En el primer nivel hay CINCO cosas:

  index.html      <- archivo

GitHub -> Add file -> Upload files. No abras las carpetas: GitHub
respeta las rutas, sobrescribe lo que coincide y no borra nada.
